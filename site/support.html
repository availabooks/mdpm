FAQ

What is a project, and what is an idea?

A project is any folder containing a .proj file. An idea is a .md or .task file that starts with a YAML front matter block. Each idea moves through the flow: idea → plan → executing → review → done.

The extension doesn't show anything.

It activates only in workspaces that contain a .proj file. Create one with mdpm: New Project, or run mdpm init tasks. If mdpm lives in a subfolder of a large repo, set the mdpm.root setting.

How do I have an agent work on an idea?

Write the idea (mdpm: New Idea, or mdpm idea "…"). The agent plans it on its next run (Plan now, or mdpm agent run). Approve the plan, and the agent builds it on its own branch and hands it to Review. It executes one idea at a time.

Why is my idea blocked?

The agent needs a decision from you. Click Answer on the card (or run mdpm unblock <id> "<answer>"); the idea goes back to where it was.

Can agents approve their own plans, accept their work, or push to main?

No. Agents propose plans and hand work off for review on a branch; only a person approves a plan or accepts the work.

Does mdpm collect my data?

No. See the privacy policy.

Which agents are supported?

Claude Code, Codex and Cursor are built in. Any CLI can be added under agents: in the root .proj.
