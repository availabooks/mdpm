FAQ

What is a project, and what is a task?

A project is any folder containing a .proj file. A task is a .md or .task file that starts with a YAML front matter block.

The extension doesn't show anything.

It activates only in workspaces that contain a .proj file. Create one with mdpm: New Project, or run mdpm init tasks. If mdpm lives in a subfolder of a large repo, set the mdpm.root setting.

How do I have an agent work on a task?

Set the task's owner to an agent such as claude, make sure it has acceptance criteria, then use Send to Agent or run mdpm agent run. The agent works on its own branch and hands the task to Review.

Why is my task blocked?

The agent needs a decision from you. Answer the open questions under ## Questions in the task, then click Unblock.

Can agents mark tasks done or push to main?

No. Agents hand work off for review on a branch, and only a person moves a task to done.

Does mdpm collect my data?

No. See the privacy policy.

Which agents are supported?

Claude Code, Codex and Cursor are built in. Any CLI can be added under agents: in the root .proj.
