Project management that your agents can read.

mdpm is project management software that helps software engineers get the most out of their Claude subscription. Write tasks in markdown, and have the agent of your choice build them while you sleep.

Install mdpm View on GitHub

How it works

1. Write tasks in markdown

Tasks are plain .md files with YAML front matter. Projects are folders. Everything lives in your repo and in git.

2. Plan on a board

A kanban board, an AI flow board and a waterfall timeline in VS Code. Drag cards to change status.

3. Agents work overnight

Assign a task to claude, codex or cursor. The agent works on its own branch and writes progress and questions back into the task.

4. Review in the morning

Handed-off tasks wait in Review with a branch and pull request. Answer questions, check the work, and mark it done yourself.

Agents never mark work done and never touch your default branch. See the agent workflow for details.

Install

VS Code extension

Search for mdpm in the VS Code Extensions view, or run:

code --install-extension mdpm.mdpm-vscode

The extension activates in any workspace that contains a .proj file.

Command line

git clone https://github.com/availabooks/mdpm
cd mdpm
npm install && npm run build
npm link -w @mdpm/cli
mdpm init tasks -n "My Product"
mdpm new "Export CSV" -o claude --template agent
mdpm agent run

Private by design

mdpm collects no data. Your tasks stay in your repo, and this site sets no cookies. See the privacy policy.
