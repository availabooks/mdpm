From idea to reviewed code, one idea at a time.

mdpm helps software engineers get the most out of their Claude subscription. Write down ideas in markdown; the agent of your choice plans them, you approve the plans, and it builds them one after another on usage that would otherwise go to waste.

How it works

1. Write an idea

Ideas are plain .md files with YAML front matter, in your repo and in git. Write what you want the way you'd prompt an agent.

2. Approve the plan

The agent reads your code and writes a plan with acceptance criteria. You approve it on the flow board in VS Code, or send it back.

3. The agent executes

claude, codex or cursor builds approved plans one at a time, on a branch per idea, and asks when it needs an answer.

4. Review the work

Finished ideas wait in Review with a branch and pull request. Accept the work, or send it back with feedback.

Agents never approve or accept their own work and never touch your default branch. See the AI flow for details.

Install

VS Code extension

Search for mdpm in the VS Code Extensions view, or run:

code --install-extension mdpm.mdpm-vscode

The extension activates in any workspace that contains a .proj file.

Command line

git clone https://github.com/availabooks/mdpm
cd mdpm
npm install && npm run build
npm link -w @mdpm/cli
mdpm init tasks -n "My Product"
mdpm idea "Export CSV"
mdpm agent run --until-idle

Private by design

mdpm collects no data. Your ideas stay in your repo, and this site sets no cookies. See the privacy policy.
